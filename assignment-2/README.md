## 1. Project Overview

Blaugrana Store is a static e-commerce website inspired by the official FC Barcelona Store. It showcases football jerseys, sportswear, and accessories.

The project focuses on creating responsive web pages using HTML, CSS, and Bootstrap.

## 2. Reference Website

Name: FC Barcelona Official Store  
URL: https://store.fcbarcelona.com/en-pk

The design is inspired by its navigation bar, product sections, colors, and product detail layout.

## 3. Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- Google Fonts

## 4. Website Pages

### Homepage (index.html)
- Navigation bar and hero section.
- Men, Women, Kids, and Accessories sections.
- Product cards with images, names, and prices.
- Add to Cart buttons.
- Footer.

### Product Page (product.html)
- Large product image, name, and price.
- Product description.
- Size selection and quantity selector.
- Add to Cart button.

### Customize Jersey Page (customize.html)
- Large jersey preview with product description.
- Selection of different kits, including Home, Away, and Third kits.
- Quality options: Stadium and Match.
- Variant selection: Men, Junior, and Women.
- Size selection from XS to 3XL.
- Option to choose a player's name or add a custom name and number.
- Competition selection (UCL or LaLiga Winners).
- Quantity selector, subtotal, and Add to Cart button.

## 5. Responsive Design

The website is designed for different screen sizes:

- Mobile: 375px
- Tablet: 768px
- Desktop: Larger screens

Bootstrap and CSS media queries are used to adjust the layout for different devices.
